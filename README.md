
 #UniLink
 
UniLink is a modern Flutter-based mobile application that connects students with recruiters in a simple, fast, and professional way.

The app aims to bridge the gap between education and career opportunities by providing a platform for networking, communication, and growth.

-- Features --
1) Authentication system (Login & Register)

2) User roles (Student / Recruiter)

3) Clean and responsive UI

4) Fast and smooth user experience

5)  Firebase integration (Authentication & Firestore)

 6) Cross-platform support (Android & iOS)

-- Built With --
Flutter

Firebase Authentication

Cloud Firestore

Dart

 Project Vision
UniLink is designed to help students and recruiters connect more efficiently, making networking easier and opening doors to new career opportunities.

# Status
 This project is under development. More features like real-time chat, social login, and advanced profiles are coming soon.
